Rampart Edge on invented notes

Rampart Edge is a 1.45 MB personal-info detector from the US National Design Studio. It is served from this site and runs in two places: her browser, before she sends a note, and the advisor’s browser, when they open it. The server never runs it. It is a third layer. The note never goes to a model whatever it says.

How it was measured, and what it does not show

  • npm run eval:rampart runs Rampart Edge on the invented notes in Node. A detail counts as caught only when every character of it falls inside something the detector flagged.
  • 40 notes is a small sample. One more missed note moves a row a lot.
  • These numbers are not comparable to the ones Rampart Edge publishes. The notes, the kinds and the scoring are ours.
  • Timing is Node on a laptop, not a phone. A phone will be slower.
  • npm run mutate breaks the code in a scratch copy and runs every test. Its list holds only the breaks someone thought of. A check that catches all of them can still miss a break nobody tried.
